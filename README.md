# Consola de administración PostgreSQL

Herramienta de terminal en Bash para Debian que administra un servidor PostgreSQL: respaldar y restaurar bases, crear, eliminar y listar bases, monitorear y cerrar sesiones activas, y gestionar usuarios y permisos.

```bash
chmod +x Adm_db.sh
./Adm_db.sh
```

Módulos en `lib/`: utilitarias, operaciones de bases de datos, gestión de sesiones y gestión de usuarios. Proyecto académico de la materia Administración de Bases de Datos.
